## Getting Started

### First Time Setup

1. **Power On**
   - Press and hold power button for 3 seconds
   - Display shows "Stealth Deck" boot screen
   - Device starts in Calculator mode

2. **Initial State**
   - Device is locked by default
   - Only calculator functions available
   - Smart features require unlock

3. **Battery Check**
   - Battery icon in top-right corner
   - Green: >50%, Yellow: 20-50%, Red: <20%
   - Charge via USB-C port (5V, 2A)

## Smart Mode

### Unlocking Device

**Unlock Sequence**: `FN + 5 + 5 + 5`

1. Hold `FN` key
2. Press `5` three times
3. Release `FN`
4. Display shows "Smart Mode"

**Note**: Sequence must be entered within 2 seconds

### Text Entry (T9)

**Basic T9 Entry**
```
Key 2: ABC
Key 3: DEF
Key 4: GHI
Key 5: JKL
Key 6: MNO
Key 7: PQRS
Key 8: TUV
Key 9: WXYZ
Key 0: Space
Key 1: Punctuation
```

**Example**: Type "HELLO"
- Press: `4 4` (H)
- Press: `3 3` (E)
- Press: `5 5 5` (L)
- Press: `5 5 5` (L)
- Press: `6 6 6` (O)

**Special Characters**
- `1`: Cycles through `.`, `,`, `!`, `?`, etc.
- `0`: Space
- `*`: Backspace
- `#`: Submit

### AI Query

**Text Query**
1. Enter query using T9
2. Press `#` to submit
3. Wait 2-5 seconds
4. Response displays
5. Scroll with `2`/`8`

**Example Queries**
```
"What is photosynthesis"
"Explain quantum physics"
"How to solve x squared equals 4"
"Translate hello to Spanish"
"Weather forecast today"
```

### Image Analysis

## Emergency Procedures

### Panic Mode

**Activate**: Press `FN + FIX` simultaneously

**What Happens**:
1. Instant screen lock
2. Return to calculator mode
3. Display fake calculations
4. Disable all wireless
5. Locked state (requires unlock code)

**Recovery**:
1. Enter unlock sequence
2. Or wait for timeout (5 minutes)
3. Then enter unlock code

### Factory Reset

**Warning**: Erases all data permanently!

1. Power off device
2. Hold `FN + 0 + 5` while powering on
3. Confirm reset
4. Device resets to factory defaults

### Lost Unlock Code

**If you forget your code**:
1. Factory reset (loses all data)
2. Or contact support with proof of ownership
